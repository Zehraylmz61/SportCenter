# Spor Merkezi Yönetim Sistemi 🏀

C# ve SQLite kullanılarak yapılmış; üye kaydı, saha kiralama ve ücret hesaplama işlemlerini yapan bir masaüstü programıdır.

## 🛠 Kullanılan Teknolojiler
* **Dil:** C# (Windows Forms)
* **Veritabanı:** SQLite
* **Editör:** Visual Studio

## 🚀 Nasıl Çalıştırılır?

1.  Yukarıdaki yeşil **Code** butonuna basıp **Download ZIP** diyerek dosyaları indirin.
2.  İndirdiğiniz klasörün içindeki **.sln** uzantılı dosyaya (örneğin `SporMerkezi.sln`) çift tıklayarak projeyi Visual Studio'da açın.
3.  Uygulamanın çalışması için **.db** uzantılı veritabanı dosyasının (örneğin `spor.db`), projenin `bin/Debug` klasörü içinde olduğundan emin olun.
4.  Visual Studio üst menüsündeki **Başlat (Start)** butonuna basarak çalıştırın.
